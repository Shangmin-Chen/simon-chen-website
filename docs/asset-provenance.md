# Asset provenance

Company marks shown with the Whoami inventory cards and expanded readers are
locally stored official logo files. They are used as supporting identity marks
and rendered at contained, aspect-ratio-preserving sizes.

| Organization | Local asset | Official source |
| --- | --- | --- |
| RESET Standard | `public/logos/reset-standard-white.png` | [RESET Standard resources](https://reset.build/resources) · [white mark file](https://reset.build/assets/reset_logo_official_white_191017.png) |
| EZ Esports | `public/logos/ez-esports-wordmark.png` | [EZ Esports wordmark](https://www.ezesports.org/images/logos/wordmark.png) |
| GitHub | `public/logos/github-invertocat-white.svg` | [GitHub brand foundations](https://brand.github.com/foundations/logo) · [official brand toolkit](https://brand.github.com/GitHub_Logos.zip) |

Sources were checked on 2026-10-15. The logo URLs are retained here for
provenance; the site uses local copies so display does not depend on the
organizations' web servers.
